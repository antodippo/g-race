# G-Race

A top-down, single-screen Formula racing game that runs in the browser. No install, no build step: the whole game is one HTML file.

**Play:** https://antodippo.github.io/g-race/

## Features

- Eight circuits traced from real Grand Prix track outlines: Bahrain, Sepang, Monaco, Silverstone, Hungaroring, Spa, Monza and Interlagos
- Ten drivers in five teams, each strong on some circuits and weak on others
- Five difficulty levels, from Easy to Legend
- Weather drawn per race (dry, wet or changeable), wet and dry tyres, and wind at Bahrain
- Fuel, tyre wear, car damage, pit stops and slipstreaming
- Championship mode with qualifying, F1-style points, a fastest-lap point, team standings and a season summary
- Team editor (livery and setup) and track editor, saved in the browser, with share codes

## Controls

| Key | Action |
|---|---|
| ↑ / W | Throttle |
| ↓ / S | Brake / reverse |
| ← → / A D | Steer |
| Space | Pause |
| F | Full screen |
| R | Restart |
| Esc | Back to the garage |

On a phone, on-screen pedals appear during the race.

## Running locally

Open `index.html` in a browser. Fonts load from Google Fonts; everything else is in the file.
